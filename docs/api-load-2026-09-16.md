## Панель Gemini API

Администратор видит занятые слоты из 4, ожидающих семафор HTTP, поминутный график за 15 минут, HTTP-попытки/ошибки/429/5xx/сетевые ошибки/прерывания, успешные резервные маршруты, среднюю длительность HTTP-попытки, суммы за 60 минут. Обновление при открытой панели раз в 15 секунд. Обычным пользователям endpoint закрыт.

Метрики собираются вокруг реального HTTP-вызова, включая стартовые проверки моделей; отмена ожидания не считается отправленным запросом. Окна состоят из текущей и предыдущих 14/59 минутных корзин. Задержка не включает ожидание слота. Ошибки разбора HTTP 200/фактчека относятся к журналу обработки, не к HTTP-ошибкам. Успешный резерв учитывается на уровне завершившегося generate после предшествующих ошибок.

Ограничение: показатели процесса с момента запуска, не долговременная статистика; буфер максимум 61 корзина, без ключей, текстов, URL и пользовательских данных. Обнуляются при рестарте. Это не процент внешней квоты Google и не количество постов. Ожидающие блокировку ключа/отложенные материалы не входят в счётчик ожидания HTTP-слота. Текущая архитектура — один процесс приложения.
