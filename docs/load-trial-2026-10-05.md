# Проверка HTTP под нагрузкой — 5 октября 2026

Владелец запросил максимальную нагрузку и включение каналов. Выполнен первый
независимый этап: чтение публичных HTTP endpoints рабочего сайта без публикаций,
платежей, изменения каналов или запросов к ИИ. Выбор между изолированным тестом
каналов и реальными публикациями пока не получен; массовое включение не выполнено.
Два канала бизнес-режима остаются отключёнными согласно предыдущему решению.
Тестовый пост с неопределённой доставкой оставлен для ручной сверки по просьбе владельца.

## Метод

Интервал: **01:28:59–01:31:16 МСК**. Один внешний адрес генератора, HTTPS
`https://flipbazar.ru`, только GET `/`, `/account`, `/healthz`, `/api/bootstrap`.
Последний endpoint вызывается без авторизации, поэтому 401 ожидаем и не является
отказом. Пять ступеней по 20 секунд, между ними 5 секунд; не более 24 запросов
одновременно. Никаких попыток обхода ограничения частоты или подмены IP.

Независимые наблюдатели на каждом VPS проверяли БД и сайт каждые 5 секунд:
на основном — внутренний healthz, на резерве — внешний HTTPS. Стоп-условия:
недоступность сайта/БД, доступная память менее 256 MiB, CPU выше 95% три среза
подряд, два медленных healthz свыше 1,5 секунды, потеря наблюдателя, HTTP 5xx
или три транспортные ошибки. После нагрузки оставлено время для проверки восстановления.

## Что доказано и что не измерено

При превышении разрешённой частоты с одного адреса лишние запросы отклоняются,
а наблюдатели с других адресов продолжают получать здоровый ответ. Границы
защиты сохранялись, сервер до исчерпания ресурсов не доводили.

Это **не максимальная пропускная способность обработки новостей**, не 100 успешных
запросов в секунду и не испытание против распределённого DDoS. Не измерялись
AI-генерация/стоимость/квоты, загрузка видео, фактическая доставка Telegram при
полной очереди, отключение primary или переключение трафика на reserve.

Дополнительно 49 изолированных тестов ограничения запросов, независимости каналов,
готовности запуска и восстановления прошли на отдельной локальной `neyro_test`.
Четыре теста генератора проверяют, что нездоровые/неполные исходные показания
наблюдателя запрещают отправку нагрузки и корректно завершают SSH-процессы.

## Повтор

`scripts/operations/load_http.py` по умолчанию показывает только план. Запуск:

```sh
PYTHON_DOTENV_DISABLED=1 .venv/bin/python scripts/operations/load_http.py \
  --run --output data/load-trial-20261005/http-report.json
```

Локальный JSON содержит все срезы и ответы по группам, без токенов/текстов постов.
Генератор предназначен только для этого проекта; секреты и обход авторизации не нужны.
