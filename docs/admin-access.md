# Управление доступом

Админ-панель позволяет выбрать тариф клиента, изменить лимиты постов/каналов и продлить срок на 0–3650 дней. Ноль означает отсутствие продления. Изменение лимитов не удаляет существующие каналы. Неадминистратору операции запрещены. Сохранение явное, после подтверждения; продление складывается с текущим действующим сроком, при истёкшем доступе считается от текущего времени. Изменённые относительно шаблона лимиты отмечаются индивидуальным тарифом.

Ключи остаются одноразовыми. Можно настроить лимиты, длительность доступа, срок активации от выпуска и необязательный Telegram ID получателя. Истёкший или чужой ключ не активируется; повторная активация ранее использованного своего ключа ничего не продлевает. Неиспользованный ключ можно удалить, чтобы отозвать. Редактирование уже использованных ключей и многоразовые ключи не добавлены.

Сохранены шаблоны start/pro/unlim, добавлен custom. Старые пользователи отображаются как индивидуальные: прежние лимиты и сроки миграция не меняет. UI называет unlim «Расширенный», поскольку лимиты у него конечные.

Реализация подготовлена локально во время двухчасового прогона. Не выкладывать до итогового сбора данных. Проверены полный прежний набор из 319 тестов, четыре новых теста прав/тарифов/ключей, UI-state и 125 сценариев адаптивной вёрстки.
