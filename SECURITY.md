# Сообщения об уязвимостях

Для непубличного сообщения используйте вкладку **Security → Report a vulnerability**
в GitHub-репозитории. Не публикуйте ключи, персональные данные и рабочие запросы оплаты
в Issues. Поддерживается текущая версия основной ветки.

Секреты хранятся в окружении сервера, закрытых локальных файлах и GitHub Environment.
При утечке ключ отзывается у провайдера; удаление строки из Git не отменяет утечку.

Порядок эксплуатации и ограничения защиты: [docs/security-defense.md](docs/security-defense.md).
